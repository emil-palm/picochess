# Internationalization (i18n)

## Overview
Multi-language support for 6 languages with display size variants.

## Supported Languages
- English (en)
- German (de)
- Dutch (nl)
- French (fr)
- Spanish (es)
- Italian (it)

## Key Components
- Translation database
- Display size variants (11/8/6 chars)
- Move notation (short/long)
- Capital letters option
