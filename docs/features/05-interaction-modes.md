# Interaction Modes

## Overview
Seven game modes controlling computer behavior and analysis display.

## Modes
- NORMAL: Play against computer
- BRAIN: Computer ponders on your time
- ANALYSIS: Continuous analysis, no play
- KIBITZ: Like analysis, different format
- OBSERVE: Watch game with analysis
- REMOTE: Play against remote player
- PONDER: Extended analysis display
